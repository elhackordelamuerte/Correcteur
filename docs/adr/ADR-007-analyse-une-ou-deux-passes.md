# ADR-007 · Deux modes d'analyse : une passe ou transcription + analyse

- **Statut** : Accepté · **Confiance** : [Observé]

## Contexte
Les copies courtes à réponses identifiables se lisent sans ambiguïté ; les copies longues ou mal écrites provoquent des contresens si le modèle lit et juge en même temps.

## Décision
- **Rapide** : une passe (lecture + évaluation), 1 crédit.
- **Approfondie** : passe 1 = transcription fidèle du manuscrit ; passe 2 = analyse de la transcription ; 2 crédits.
- Même format de sortie dans les deux cas. Modes mélangeables au sein d'un paquet. Règle d'usage : « si vous auriez lu cette copie deux fois vous-même, prenez l'approfondie ».

## Conséquences
- (+) Le coût suit la complexité réelle (deux appels IA = deux crédits).
- (+) La transcription est un artefact intermédiaire exploitable (signalement des mots douteux plutôt qu'interprétation).
- (−) Choix supplémentaire à expliquer à l'utilisateur.

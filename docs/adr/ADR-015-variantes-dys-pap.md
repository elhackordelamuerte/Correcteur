# ADR-015 · Variantes DYS/PAP à coût fixe, total conservé, sans marquage

- **Statut** : Accepté · **Confiance** : [Observé]

## Contexte
Obligation légale d'adaptation (loi de 2005) ; risque de stigmatisation ; besoin de notes comparables.

## Décision
- Variante générée à partir de l'évaluation d'origine : transformations de **forme** uniquement.
- Invariants : niveau d'exigence et total de points identiques ; barème recalculé sur le même total.
- 3 intensités, 8 besoins fonctionnels (pas des diagnostics).
- Aucune mention sur la feuille remise à l'élève.
- Statut proposition → validée ; impression bloquée avant validation ; toute modification renvoie en proposition.
- **Prix fixe (2 crédits) indépendant de l'intensité**, disponible dans les deux forfaits.

## Conséquences
- (+) Équité tarifaire et éthique explicite (« pas une option premium »).
- (+) Liste des transformations affichée pour contrôle.
- (−) Vérification que la génération respecte le total : même contrôle logiciel que pour le barème ([ADR-006](ADR-006-bareme-avant-correction.md)).

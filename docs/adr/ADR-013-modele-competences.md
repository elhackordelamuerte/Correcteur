# ADR-013 · Modèle de compétences à trois statuts, alimenté par critères validés

- **Statut** : Accepté · **Confiance** : [Observé] (règles) / [Hypothèse] (calcul)

## Contexte
Transformer des notes en diagnostic actionnable, dans un langage commun avec l'institution.

## Décision
- Référentiel : compétences codées d'après le socle commun et les repères officiels (`FR.GRAM.03`, `FR.ECRIT.01`).
- Trois statuts alignés sur les évaluations nationales : **à besoins / fragile / satisfaisante** (+ non évaluée). Côté élève : « À travailler / En cours / Tu maîtrises ».
- Signal = critère de barème rattaché à une compétence, sur une **copie validée**. Les exercices produisent un signal de poids inférieur.
- Pas de signal pour : copie non validée, correction entièrement manuelle (pas de grille appliquée), critère sans compétence.
- Historique cumulé ; courbe dès deux points.

## Conséquences
- (+) Le suivi se remplit sans saisie (« 0 tableur »).
- (+) Incitation économique implicite : la correction manuelle est gratuite mais n'alimente pas le suivi, ce qui valorise l'analyse IA.
- (−) Qualité du suivi dépendante du rattachement critère ↔ compétence fait au moment du barème.
- (−) Algorithme d'agrégation non public (seuils, pondération, fenêtre temporelle).
